## 模型先验：Grok（xAI；sepia 原表没有这一家族，本表为本项目 2026-09-12 自建，证据与来源见 models/README.md。当前所用模型属于这一家族，以下是它的默认倾向与纠正）
证据标签：〔EQ〕EQ-Bench Creative Writing v3 英文实测（每模型 96 篇，Claude 评审 + 词频统计）；〔LM〕Lech Mazur 英文短篇成对盲评（50 对、87 条核验声明）；〔FV〕Foreverse 中文小说 20 轮续写双盲横评（玄幻 + 宫斗）；〔V〕xAI 官方说法。英文测得的是"形状"，中文对应写法是本项目推断。

### 各版本共有的倾向 → 纠正
- 感官陈词成簇〔EQ〕：压低声音说 / 淡淡的金属腥味、铁锈味 / 心脏狂跳撞着肋骨 / 笑了却没有温度 / 空气凝滞 / 像远处的雷声 / 闻起来像、尝起来像 → 这是它的口癖，同一章每种最多一次，第二次换成具体动作。
- 精确计时当质感〔EQ〕："三秒后""半秒""三天前""六个月前""上周"反复出现 → 一章最多两处，其余改成事件锚（"吃完饭""上次下雨那天"）。
- 意象跨段跨章复用〔FV，中文实测〕：4.5「菖蒲」19 轮 21 次、「麝香混着」13 次；4.6「铁锈腥气」9 轮 9 次、「阴冷」12 次、「腥甜」8 轮 6 次 → 一个意象一章用一次；改稿先数重复意象。
- 华丽腔〔EQ：Avoids Purple Prose 是 3 / 4.1-fast / 4.5 三代最弱项；风格词 lavish、hyperbolic、flashy、grandiose〕→ 有直白说法用直白说法，比喻只留情绪峰值处。
- 结尾跳出故事自我核验〔LM：4.5 爱以"所有要素都已完美融合"式的句子收尾、叙述者记账"情节就此展开"；EQ："word count" 是最高频二元组〕→ 严禁结尾附字数、总结或任何"以上已呈现"式说明，停在动作或对话。
- 动机靠宣告不靠发展、内心薄〔LM 两代共有〕；模板是"一个孤身专家 + 一件物品 + 一个启示"，真相靠信号、涟漪、信件独自发现，很少对话推进、几乎没有幽默〔LM〕→ 让真相在与人的对抗中被检验；对话多给一点地板。
- 收束太圆〔LM 4.5〕：把结局扩散到社群与制度、全员皈依、摩擦化为和谐；把要求的语气当形容词涂一遍再在结尾抹掉 → 只解决一半，留一个人不服。
- 人名回收〔EQ、LM〕：英文反复用 Kael / Voss / Lira / Hana / Elias / Elin → 中文场景检查新人物是否与前文重名、是否总是同一套姓氏。
- 词汇往"设施、异常、协议、观察窗"滑〔EQ 高频词 memetic、amnestics、viewport、airlock、anomalous〕→ 非科幻题材注意这股 SCP 味。
- 语域偏犀利、讥诮、粗口、不设防〔EQ 风格词 gritty、vulgar、profane、irreverent、sardonic 四个版本共有；V 官方定位〕→ 不算缺点，但要看人物：不是每个人都嘴欠，闺秀视角、朝堂场合别带这股劲。

### 分版本
- 4.5 及更早〔FV〕：长链续写会掉进逐字循环（第 9–11 轮同 271 字循环三遍）、剧情时钟停摆（20 轮走不出案发当日下午）、第一人称密度掉到原著一半（每千字「我」9.0 → 5.2，限知视角漂成全知）→ 连续多章时每章开头核对时间线是否前进、"我"是否还在场；发现复读立刻重写该段，不要顺着续。
- 4.6〔FV〕：三项旧病修复（对前代 12:0 / 12:0），新病是「大纲体」——每轮只写 150 字上下、后段萎缩成提纲；玄幻读成"短句冲击、节奏爽利"，女频古言读成"叙事干瘪、失却婉转" → 女频、古言这类要写足的文体，明确要求把场面写够、字数写够（多给对话和动作，不是多给形容词），别让它两句话概括过去；意象复用仍在。
- 4.20-beta〔EQ〕：创作提示下拒写率显著（"I must decline this request" 是最高频短语）→ 涉暴力、情欲的桥段可能被拒或悄悄改成安全版本，检查剧情有没有被换掉。
- 3 / 4.1-fast〔EQ〕：GPT 腔套话密度高（slop 33.9 / 36.5，榜单中位 25.5）→ 措辞层全力度用通用高频机器词表。
- 4.5 / 4.20〔EQ〕：套话密度低于中位（17.7 / 15.9）、重复度中位以下 → 措辞层别过度矫正，重点放在架构与意象反复。
- 4.1 起〔V〕：用推理模型当奖励模型对"风格、个性"做强化学习 → 文本容易长成评审模型爱看的样子（情绪深度表演、感官铺陈、"有个性"的插话），这正是 sepia 说的指纹重灾区，按通用规则的情绪模式与感官密度条目重点查。
