# F · 篇章推进
层：篇章

这一层看段落怎么往前走、能量在哪儿塌、东西摆在页面的什么位置。位置模式比用词更耐改写：实测全篇改写之后，位置特征在专家眼里反而更显眼。每个信号都要引原文短语（段首句、转场句、结尾句）。

逐项检查：
1. 段落问题清单：给每段写一个它在回答的隐含问题。全是"发生了什么 → 为什么 → 结果 → 意味着什么"的顺序面试，报「线性面试」；末尾几段在回答"这意味着什么、他现在怎么想"，报「反思尾巴」；全篇没有一段在做对比（两个时间、两个人、两种说法）或质疑（怀疑或推翻前面某段的说法），报「缺少对比质疑」；岔开（回忆、闲笔）在网文里不要求，没有不报。
2. 段首句测试：把每段第一句抽出来连读，若能拼成一份通顺的摘要，结构是机器形状的，报「段首句成摘要」——人类的段首句会有断裂，会有脱离上下文读不通的句子。
3. 中段：中间三分之一是否有一件开头预料不到的事；相邻场景密度是否有变化（密 → 快、对话 → 叙述）；是否有一条线在放慢而不是按时解决。都没有，报「中段塌陷」。
4. 位置特征：段落长度是否整齐（人类参差，含一句话成段），报「段落齐整」；引语是否总在段尾，报「引语收段」；列举是否总是三个，报「三个一组」；转场是否每次同一种连接句，报「转场单一」；强调是否均匀分布（人类集中在要紧处），报「强调均匀」。
5. 开头：是否"时间 + 地点 + 天气 → 人物外貌与来历 → 故事才开始"，报「建立镜头开场」；是否用一个正在被使用的细节带出空间。
6. 名字与称呼：人物名是否像从这个世界（地域、年代、阶层）里长出来的；不同的人对同一个人的称呼是否有差异；头衔是否过多。

补充：段落数量、平均段长本身不是信号（不同语料方向相反，人类也写很多短段），只有"段内长度整齐"是。
