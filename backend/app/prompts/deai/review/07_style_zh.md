# G · 中文措辞
层：措辞

最后看这一层，结构问题优先。单个命中不算，成群才报；每条都要引原文。语料参考（HC3 中文，2023，人类 vs AI）：句长标准差 9.2 vs 6.7（词）；连词密度 0.013 vs 0.036；语气词密度 0.016 vs 0.003；单音节词占比 0.48 vs 0.38；型例比 0.73 vs 0.54。这些是方向，不是阈值。

| 特征 | 怎么判 |
|---|---|
| 句长扁平 | 相邻三句以上长度接近。不要用平均句长判（不同语料方向相反），也不要数短句或长句的个数 |
| 连词堆叠 | 和、以及、并且、同时、此外、因此、然而、与此同时 串着用；「和」连接整句 |
| 对比框架 | 「不是……而是……」「这不是 X，而是 Y」 |
| 名词化 | ○○性、○○感、○○化 当主语；「一种……的感觉」「……的重量」；「自我的探索」代替「找自己」 |
| 双音节填充 | 进行讨论、加以说明、予以处理、做出决定 |
| 段首套话 | 其实……、事实上……、值得注意的是；抽象词加引号强调 |
| 滤镜词 | 感到、似乎、仿佛、意识到、注意到、发现、看着……（隔在读者和事情之间的词） |
| 高频机器词成群 | 仿佛、不禁、顿时、一丝、一抹、一股、这一刻、空气仿佛凝固、嘴角勾起、眼神一凛、深吸一口气、露出一抹笑 |
| 尾随分句重述 | 「……，在……中投下长长的阴影」式的后置分句只是重述主句 |
| 三个一组 | 三个并列形容词、短句、意象反复出现 |
| 说话标记轮换 | 低声道、沉声道、淡淡道、轻笑道 轮着用（重复「说、道」是人类习惯） |
| 缺少口语层 | 全篇零语气词、零省略主语、零单音节口语词（公文、朝堂等正式场合除外） |
| 用词重复 | 同一段反复同一个词、同一个比喻 |
| 读不出口 | 语法对但没人会这么说的句子，对话尤其要读出声检查 |

白名单，不要报：语法干净、标点规范；单个破折号、分号、"仿佛"；正式场合的正式语气；引语里的任何用词；项目风格或作者样本里确认的习惯；平淡普通的句子；标点数量、段落数量、平均句长。
